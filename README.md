# Premium Website Engine

A reusable AI-assisted workflow for premium business websites. Initial vertical: restaurants. Primary differentiator: exceptional visual design and purposeful animation.

## Start here
1. Read `AGENTS.md`.
2. Read `blueprint/MASTER.md` and `blueprint/REFERENCE_SPEC.md`.
3. Copy and complete the client templates.
4. Follow `blueprint/WORKFLOW.md`.
5. Use `blueprint/QA.md` before handoff.

## Initial stack
- Next.js + React + TypeScript
- Tailwind CSS
- GSAP + ScrollTrigger for complex scroll-linked storytelling
- Native CSS for simple transitions
- Playwright for browser QA
- Lucide icons sparingly
- shadcn/ui selectively for functional primitives, not as the visual identity

This is the operating blueprint; it does not install an app. Use current official setup instructions when initializing the project.
