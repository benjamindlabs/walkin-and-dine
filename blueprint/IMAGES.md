# Image and Asset Handling

Inventory images before design: filename, dimensions, aspect ratio, format, size, likely subject, suggested placement, and concerns. Visually inspect when possible.

- Use sufficiently high-resolution hero assets.
- Crop intentionally and preserve focal subjects on mobile.
- Avoid unnecessary image repetition.
- Never stretch logos or low-resolution assets.
- Use framework image optimization and responsive sizes where appropriate.
- Reserve dimensions to reduce layout shift.
- Lazy-load suitable below-the-fold images; prioritize the hero.
- Keep originals and generate derivatives separately.
- Do not imply AI/stock images depict the actual client, premises, staff, or food.
- Use assets only when supplied or appropriately licensed.
