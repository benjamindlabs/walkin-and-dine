# Standard Website Production Workflow

1. **Inventory assets:** filename, format, dimensions, likely subject/use, duplicates, quality concerns. Preserve originals.
2. **Extract facts:** separate verified facts, approved copy, creative recommendations, and missing information.
3. **Choose art direction:** one-sentence concept, palette, type roles, image approach, page narrative, motion plan, mobile adaptations.
4. **Implement structure:** build hero and core sections; establish typography, spacing, and color before effects.
5. **Add motion:** one pattern at a time; keep reduced-motion behavior usable.
6. **Browser review:** first viewport, every major section, nav, CTAs, menu/offerings, footer, mobile, reduced motion, console/network issues.
7. **Refine in order:** facts, broken functionality, composition, imagery/crops, spacing/type, motion, decorative details.
8. **Handoff:** run instructions, QA results, known gaps, concise change summary.
