# Accessibility Baseline

- Use semantic landmarks, headings, buttons, and links.
- Maintain logical heading order and keyboard navigation.
- Provide visible focus and sufficient contrast.
- Give informative images useful alt text; mark decorative imagery appropriately.
- Label form controls and provide understandable errors.
- Ensure menus/dialogs support keyboard operation and focus management.
- Respect reduced-motion preferences.
- Do not communicate meaning through color alone.
- Avoid autoplaying audio and provide controls for meaningful video.
- Keep core content/actions usable without animation.
- Enforce human/accessibility criteria via `antislop-human` (verify color contrast against WCAG AA 4.5:1 / 3:1 using `contrast-check.py`; never eyeball contrast over images or text pairs).
