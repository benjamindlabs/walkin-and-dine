# Performance Baseline

- Keep dependencies minimal and justified.
- Avoid overlapping animation libraries.
- Optimize images for actual placements.
- Prioritize the hero; lazy-load suitable lower-page media.
- Avoid unnecessary client-side rendering for static content.
- Avoid large background videos unless they materially improve the experience and have a fallback.
- Prefer transform/opacity animation.
- Reserve media dimensions to avoid layout shift.
- Check console errors, network failures, and mobile performance before handoff.
